[![License](https://img.shields.io/badge/License-MIT-rose.svg)](LICENSE)

**CineVerse** is a modern movie ticketing web application built with **React 19**, **Vite**, and **Tailwind CSS**. It bridges the excitement of **2026 epic blockbusters** (such as Nitesh Tiwari's *Ramayana: Part 1*) with **timeless vintage classics** (*Sholay 70mm*, *Mughal-e-Azam*, *DDLJ*, *The Godfather*), integrated with real-life iconic multiplexes across Indian metropolitan hubs.

### 🎟️ The Interactive Booking Experience

1. **City Selection**: 1-click modal with search and auto-detect GPS simulation.
2. **Hero Carousel**: Auto-sliding cinematic showcase with trailer player and quick booking.
3. **Showtime Picker**: 7-day calendar, morning/afternoon/evening/night filters, and color-coded seat filling status.
4. **Curved-Screen Seat Selection**: Realistic auditorium layout with ambient neon screen glow:
   - **VIP Plush Recliners** (Rows A-B)
   - **Prime Dolby Club** (Rows C-F)
   - **Classic Executive** (Rows G-K)
5. **Cinema Concession Stand**: Fresh Golden Caramel & Wisconsin Cheddar popcorn, loaded nachos with jalapeño cheese, and blockbuster couple combos.
6. **Checkout & Billing**:
   - Itemized bill, convenience fee, and 18% GST.
   - Working coupon codes: `BLOCKBUSTER`, `CINE20`, `HDFC100`.
   - Simulated UPI QR code, Credit/Debit card, and NetBanking payments.
7. **Digital Boarding Pass M-Ticket**: Turnstile QR code, screen & seat numbers, confetti celebration, and 1-click ticket printing.
8. **Persistent "My Bookings"**: Saved in `localStorage` with view ticket and instant refund cancellation.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/keshavdhiman03/cineverse-booking.git

# Navigate into the project directory
cd cineverse-booking

# Install dependencies
npm install

# Start the Vite development server
npm run dev
```

Open `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
npm run preview
```
